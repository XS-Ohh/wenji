# 需求基线摘要

项目：文迹，大学生文化研学与城市探索系统。周期3周，团队3人，采用Vue 3前端、Spring Boot 3单体后端和MySQL 8。

## P0范围

1. 注册登录、JWT、个人资料与角色权限。
2. 文化资源分类、分页搜索、详情、收藏和后台维护。
3. 研学计划与路线节点增删改、排序、时间安排和状态管理。
4. 后端AI路线适配、结构校验及无密钥规则降级。
5. 图片上传、文化地点打卡和管理员审核。
6. 研学笔记、积分、等级和至少6项幂等成就。
7. 个人文化足迹大屏与管理员概览。
8. 初始化数据、OpenAPI、自动化测试、README和演示材料。

## 边界

不做支付购票、真实导航、社交聊天、全国数据抓取、模型训练、微服务、Kafka、Elasticsearch或原生App。P0全部通过前不进入P1。

详细字段、接口、页面和验收标准以用户提供的 `wenji_codex_project_spec.md` 为需求源；本文件用于仓库内快速定位范围，不替代原规格。
